OASIS（オエイシス）

Native Pronunciation Meets Playful Japanese Expression.

英語の発音を、ネイティブの音に寄せてカタカナで表現する。

教科書どおりのカタカナではなく、実際にネイティブの口から飛び出す音を、日本語で楽しむための対話型プロンプト作品です。

Hear it. Feel it. Say it.

⸻

What is OASIS?

OASISは、英語などの外国語の発音を、日本語話者にもイメージしやすいカタカナで再現する実験的なプロンプト作品です。

アメリカ英語を基本とし、音の連結、弱化、脱落、アクセント、リズムなどを考慮して、自然な発話に近い表現を目指します。

正確さを大切にしながら、ちょっと大げさで、思わず笑ってしまうような表現も楽しめます。

Examples

Input

What a beautiful day!

Output（例）

ワッ ァ ビューリフォゥ デェイ！

※出力は発音表現の一例です。実際の発音や話し方によって表現は変わります。

Features

* Native-like pronunciation
    ネイティブの自然な発音を意識したカタカナ表現。
* Connected speech
    音の連結、弱化、脱落など、文章全体の発話を考慮。
* Playful expression
    正確さを損なわない範囲で、勢いと遊び心をプラス。
* Flexible input
    単語、フレーズ、文章、日本語と外国語の混在表現、擬音語・感嘆詞などに対応。

How to Use

Recommended: ChatGPT

1. prompt.md を開く。
2. プロンプト本文をコピーする。
3. ChatGPTで新しいチャットを開く。
4. コピーしたプロンプトを最初の指示として貼り付ける。
5. 英語の単語や文章を入力して楽しむ。

Other AI Systems

OASISは、適切な指示文を解釈・実行できる他のAIシステムでも利用できる場合があります。

プロンプト本文をコピーし、各AIシステムのカスタム指示やシステムプロンプトなど、適切な場所に設定してください。

ただし、対応状況や出力品質はAIモデルやサービスによって異なります。ChatGPT以外での動作や品質を保証するものではありません。

About NOMINARIUM

Nominarium is an open nomination project: a place to collect cultural fragments and things worth appreciating.

Anyone can nominate something they like by posting it with #ノミナリウム on X.

Nominations are collected throughout the year, with the annual grand prize quietly announced by the organizer at the end or beginning of the year.
